### 2.2 三个信号（SIGNAL）

1. **涨价不等于成交火热。** 指数在涨，但新房销量腰斩、二手持平；价格由少数成交撑起，不是由广泛需求推起。
2. **RCR 横盘、OCR 补涨。** 资金在追『便宜』，不在追『地段』。对 Normanton Park 这种 RCR 边缘、价格接近 OCR 新盘的项目，这是双刃剑：它便宜，但它的买家也可能被 OCR 新盘分流。
3. **资金便宜了，供应也多了。** SORA 1.26% 下，浮动房贷已报到 1.5% 左右、两年固定 2.3%–2.4%；但 32,800 套未售供应、2027 年约 1.1 万套竣工（行业估算）+ 7.2% 空置率，意味着 2027–28 年价格需要更强的真实需求支撑。
4. **组屋：量升价弱，但百万组屋创纪录。** Q3 2026 百万组屋约 597 宗（占比约 7.8%，首次单季破 500），其中五房及以上占 59.1%，均价约 S$1.16M；女皇镇 SkyTerrace @ Dawson 五房 S$1.6M 创全岛 psf 纪录 S$1,502。对路径 B 的意义：**好地段大户型组屋并不便宜，也不会等你。**

## 4 · 本质一：时间与规模（INSIGHT）

**时间：** 99 年地契不是永久土地。剩余约 92 年时，银行贷款、CPF 使用都不受影响；地契折价通常在剩余 60 年以内才显著，**未来十年地契不是主要风险**。真正的时间风险在第 30–40 年之后，而那时你早已不是持有人。

**规模：** 1,862 户的项目，内部供应永远充足。这带来三个后果：
- 价格由『同项目最急的卖家』定，而不是由『最想要的买家』定；
- 你的单位要卖出溢价，只能靠装修、时机与耐心，而不是靠项目名气；
- 流动性好（永远有人看、有人买），但定价权弱。

**位置：** one-north / 科学园 / 国大 / 国大医院构成稳定租客池。Q3 三房租金中位数 S$5,800/月（39 笔租约），对基准估值毛回报 3.08%。

**结论：它是一个现金流型资产，不是稀缺型资产。** 现金流型资产的正确玩法是收租和等待，而不是博取暴涨。

## 6 · 账面 vs 真实回报（SELLER MATH）

以基准 S$2.26M 成交为例。持有成本为示例假设（贷款 S$1.5M、平均利率约 2.8%、管理费 S$400/月、自住物业税）。

| 项目 | 金额 | 说明 |
|---|---|---|
| 假设成交 | S$2,260,000 | 基准情景 |
| − 2021 买入价 | −S$2,002,000 | |
| = 账面毛增值 | **+S$258,000** | +12.9% |
| − 中介佣金 2% + 9% GST | −S$49,268 | 示例 |
| − 律师费 | −S$2,500 | 示例 |
| − 2021 买方印花税（BSD） | −S$64,680 | 旧税率 |
| − 五年持有成本（假设） | −S$230,000 | 利息约 S$195K + 管理费约 S$24K + 物业税约 S$9K |
| = 价格部分净结果 | **≈ −S$88,000** | **只靠涨价，这笔投资是亏的** |
| + 五年居住价值 | +S$318,000 | 省下的租金，约 S$5,300/月 × 60 月 |
| = 真实经济回报 | **≈ +S$230,000** | 对约 S$570K 自有资金（25% 首付 + BSD），年化约 7% |

**INSIGHT：** 年化 7% 不差，和一个不错的平衡型组合相当。但它几乎全部来自**居住价值 + 杠杆**，而不是房价本身。这决定了后面每一条路径的逻辑：
- 如果你继续需要在这一带居住，持有的『隐性回报』仍然成立；
- 如果你可以用更低的成本解决居住（例如转售组屋），持有的理由就只剩下『对未来涨幅的预期』，而这正是本项目最弱的一环。

**现金回款公式（卖出时真正能拿回银行账户的钱）：**
`现金回款 = 售价 − 剩余房贷 − CPF 应退本金及累计利息 − 交易与结算费用`
CPF 退款回到你的 CPF 账户，不是损失，但也不是可自由支配的现金。

## 8 · 作为已拥有的资产：怎么配置

### 8.1 三条路径

| | A · 继续持有（自住或出租） | B · 卖出 → 换购转售组屋 | C · 卖出 → 换另一套私宅 |
|---|---|---|---|
| 核心逻辑 | 收租 / 自住 + 等待温和升值 | 去杠杆 + 锁定居住成本 + 释放资金 | 换一个买入价更低 / 更稀缺的标的 |
| 现金流 | 租金 S$5,800/月 · 毛 3.08% · 净约 2.3%（扣物业税、管理费、空置、中介）· 房贷约 1.5–2.4% → 正利差 | 示例释放现金约 **S$0.5–0.7M** + CPF 退款回户口 | 往返交易成本约 **6–8%**（BSD 3–5% + 中介 2.18% + 律师） |
| 预期回报 | 价格年化 +2–3% → 杠杆后权益回报 **5–8%** | 居住成本降至接近零负债；释放资金按 4–5% 配置 | 只有新标的**跑赢 10–15%** 才能覆盖摩擦成本 |

**决策不是比较哪条路『赚得多』，而是比较哪条路与你的家庭现金流、居住需求、风险承受最匹配。**

## 10 · 决策触发器（把判断写成可执行的条件）

**倾向出售，当满足其中两条：**
1. 同户型真实成交稳定在 **≥ S$2,150 psf**（约 S$2.36M）
2. 目标组屋已锁定，HFE 已批
3. 家庭需要降杠杆或释放现金
4. 房贷重新定价后利率 **> 3.5%**

**倾向持有，当满足其中两条：**
1. 租金 **≥ S$5,800** 且空置 < 1 个月
2. 房贷利率 **≤ 2.5%**（正利差）
3. 没有明显更优的替代资产
4. 未来 3–5 年仍需在这一带居住

**永远不做：**
- 因为『指数涨了』就急着卖
- 因为『挂牌价高』就定高底价
- 没算清贷款余额与 CPF 退款就签约
- 为了省 15 个月而先买后卖，却没备好过桥现金
