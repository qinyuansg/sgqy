# 造物者视角 · QY 八维

一支 2 分 30 秒的竖屏（1080×1920）科普动画，用“造物者视角”拆解八维优势雷达：把 8 个维度看成一台机器的 3 个引擎，讲每个维度的本质和底层逻辑，再指出瓶颈和突破口。

| 文件 | 用途 |
|---|---|
| `index.html` | 动画本体，可以直接在浏览器播放。开场可以选 YouTube 背景音乐、本地音乐文件或静音。空格键播放/暂停，← → 每次跳 5 秒 |
| `qy-8d.mp4` | 成片，配的是合成的氛围占位音乐 |
| `render.cjs` | 逐帧导出无声 MP4：`node render.cjs out.mp4`；`--stills 3,40` 导出指定秒数的截图 |
| `ambient.py` | 生成占位配乐：`python3 ambient.py ambient.wav` |
| `add_music.sh` | 换成你自己的音乐：`./add_music.sh silent.mp4 song.mp3 out.mp4 [起始秒]` |

## 结构（时间轴）

| 时间 | 段落 | 核心观点 |
|---|---|---|
| 0:00 | 序章 | 如果你是被设计出来的，设计图长什么样？ |
| 0:08 | 结构 | 8 个维度不是一张清单，而是一台机器的 3 个引擎 |
| 0:17 | 引擎 | 认知（输入）→ 判断（决策）→ 交付（输出），由“复用”接回输入 |
| 0:29 | 8 个维度 | 每个维度讲 4 件事：部件、本质、底层逻辑、造物者批注 |
| 1:45 | 诊断 | 输入端强、输出端弱；管道的流量由最窄处决定 |
| 1:58 | 飞轮 | 选定主线 → 拿到基线 → 交付并量化 → 换场景复验 → 沉淀方法 |
| 2:09 | 目标 | 从相对优势到绝对优势：成果证据 4→9、技术 6→9、组织 6→9 |
| 2:19 | 结语 | 持续提高同一条主线上的成果密度 |

评分口径和原图一致：分数是根据交流记录做的主观估计；带 * 的维度证据较少，分数低不等于能力弱；目标分只用来安排投入，不算总分。
