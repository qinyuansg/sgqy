# 身体三层模型 · 健康数据科普动画

把 2026‑08 ~ 2026‑10 三个月的智能指环数据（活动卡路里 / 睡眠 / HRV / 心率 / 血氧）
做成一支 104 秒、1080×1920 竖屏的解析动画。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 动画本体（单张 Canvas，按时间 `t` 确定性绘制）。浏览器直接打开可预览，支持拖动进度条、空格播放，并可 **选择本地音乐文件** 同步播放。 |
| `data.js` | 从 App 截图提取的数据。月度汇总为 App 原值，每日柱状为按比例估读的示意值。 |
| `music.py` | 替代配乐生成器（numpy 合成，96 BPM，与画面共用同一条能量曲线）。 |
| `render.js` | Playwright 逐帧截图 → ffmpeg 编码 → 混入配乐，输出 `health-story.mp4`。 |
| `soundtrack.wav` | 由 `music.py` 生成的配乐。 |
| `health-story.mp4` | 成片。 |

## 叙事结构（与音乐能量曲线一一对应）

| 时间 | 段落 | 音乐 | 画面 |
|---|---|---|---|
| 0–8 s | 冷开场 | 只有低音垫 + 72 bpm 心跳 | 心率脉冲环，“你的身体每天都在写日记” |
| 8–22 s | 第一层 · 全貌 | 轻踩镲进入 | 五张指标卡逐拍落下，归并为 输出 / 恢复 / 基础 三层 |
| 22–40 s | 第二层 · 输出层 | 底鼓 + 贝斯 | 10 月每日卡路里柱、三月均值 623→676→864、+39% |
| 40–58 s | 第三层 · 恢复层 | 踩镲加密、和声变暗、riser | 睡眠分数↑时长↓；HRV 均值不动而地板 20→11→3 |
| 58–74 s | 本质（Drop） | 全编制 + 琶音 | 进步 = 负荷 × 恢复；“发动机升级 39%，冷却系统没变” |
| 74–90 s | 极致框架 | 律动保持、和声明亮 | 四条底层逻辑，一小节一张卡 |
| 90–104 s | 行动 + 收束 | 渐弱回到心跳 | 三个动作、数据缺口提醒、结语 |

## 换成你自己的背景音乐

渲染环境访问不到 YouTube，所以成片用的是合成配乐。拿到你想用的音频文件后：

```bash
# 直接替换音轨（不重新渲染画面）
ffmpeg -i health-story.mp4 -i your-music.m4a -map 0:v -map 1:a -c:v copy -c:a aac -shortest health-story-final.mp4
```

若希望画面节奏重新对齐新音乐，可改 `index.html` 顶部的 `BPM` 与 `ENERGY` 曲线，再执行：

```bash
python3 music.py soundtrack.wav        # 可选：重新生成替代配乐
node render.js --audio your-music.m4a  # 逐帧渲染（约 10 分钟）
node render.js --preview               # 只出关键帧 PNG，用于检查排版
```

> 数据仅供个人参考，不构成医疗建议。
