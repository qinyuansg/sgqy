## 1. 核心命题与视觉母题

### 1.1 核心命题

> “千年，不过是无数个普通人，舍不得结束的今晚。”

把命题翻译成可执行的影像规则：

1. **尺度法则 —— 先给天地，再收回到手。** 每个时代第一次出现时，先用一个有重量的远景（海、港、礼拜堂的高处、长廊的纵深）让人物变小，再用缓慢的推近或剪辑，把历史收回到一张脸、一只手、一件物上。简报原话：“摄影从远景慢慢走向近景，把历史的辽阔收回到人的脸和手。”
2. **留白法则 —— 一个人物只交代“一个动作 + 一件物”。** 航海人：摸袖口补丁 / 罗盘。等待的人：冷饭与空座 / 青花碗。迁徙女性：折衣入箱 / 藤箱与信。母亲：颤抖的双肩 / 折叠的信。我们不交代任何人的结局，不解释任何人在为谁等待、为什么祈祷。
3. **治愈法则 —— 治愈来自“坐到身旁”，不来自答案。** 全片的情感高点不是奇观，而是“一个人终于坐到了另一个人身旁”。所有历史人物在最终副歌里也各自完成了一次“坐到身旁 / 给出一点温暖”的动作。
4. **主角弧线 —— 从“隔着玻璃”到“没有玻璃”。** 修复师读得懂年代，读不懂人。前八章她的手始终戴着手套、始终隔着玻璃；第八章她摘下手套，把一杯茶放在一个活人身旁。最后一个画面里，两只茶杯并排放着，中间没有任何玻璃。

### 1.3 一句话美术立场

辽阔而亲密：每一个宏大远景都必须含有一个具体的人；每一个亲密特写都必须让人感觉到它背后的天地。美，但不甜腻；旧，但不发黄；伤感，但不哭泣——全片无人落泪特写，情绪靠肩膀、手指、呼吸与停顿。

### 2.2 肤色保护【锁】

- 面部中间调 HSL 色相 18°–32°，饱和度 25%–45%；月光场景可降至 18%，但色相不得低于 15°（偏品红）或高于 38°（偏黄绿）。矢量示波器上肤色保持在肤色线 ±5° 以内。
- 冷调调色只作用于阴影与空气，**面部永远保留一丝暖**：月光下的脸 = 冷边缘光 + 暖的反射补光（墙、木、纸张的反光）。
- 禁止磨皮、美白、塑料质感、“美颜”。保留毛孔、细纹、眼下的疲惫、航海人手上的裂口。
- 东亚人物肤色自然而有差异：航海人与同伴为长期日晒的深暖肤色（P19）；修复师为少见日光的浅暖（P17）；母亲与夜班员工为中间（P18）；不同人之间不得被调成同一种肤色。
- 禁止“亚洲题材黄绿滤镜”与整体泛黄的“怀旧”处理：旧时代的“旧”来自褪色与颗粒，不来自黄色。

### 2.6 色彩纪律

1. 禁止“青橙大片调色”。蓝是深蓝与银蓝，不是青（cyan）；暖是琥珀与铜，不是橙色皮肤。
2. 黑位底线 P28：任何画面暗部必须读得出层次（暗部层次是简报要求）。
3. 小红 P16 仅三处：罗盘针南端红漆、油纸糖红绳、迁徙女性梳子的包布（深一档 `#8E4A3C`）。它们都指向“家”。地图上的线**不用红色**（见 PROP_MAP）。彩窗绛红与信笺的褪色朱红格线属于材质本色，不计入，但同样保持低饱和。
4. 绿色全片压低，只允许：铜绿锈斑、彩窗海青、母亲的旧玉镯。
5. 同一件物在不同时代的色值变化必须是“老化”方向的（见 §6 各道具的“当年 / 博物馆”双状态）。

### 3.4 各场景光线方案

**LOC_GALLERY 展厅（`museum_gallery`）**：夜间模式。主光为展柜内 3000K 小光源（罗盘柜：顶部一盏窄角射灯 + 底部极弱的反光板）；空间光为月光从南侧五个拱形门洞（通往长廊）成束斜入，在地板上形成冷银拱形光斑；铸铁柱在光斑中投下长影。背景偶有夜班员工手电筒 4000K 扫过（INTRO 一次）。罗盘柜玻璃的反射条件：柜内衬布为近黑深蓝，柜外修复师身后是暗，故玻璃中的船灯海面可“亮于”背景而被看见。

**LOC_LAB 修复室（`restoration_lab`）**：主光为可调臂台灯 3500K，从画左上方 45° 落在工作台；窗（南）外是港口夜灯与月光，作为背景冷光与玻璃反射源；侧墙书架上一盏 2700K 小灯作为远处暖点。台灯被修复师推开、拉近都是有意义的光变化（例如 BR1 后段她把台灯拉低，光圈只剩信纸大小）。

**LOC_CABIN 船舱（`ship_cabin`）**：唯一主光为横梁上悬挂的角片手提灯（内为蜡烛）1950K，随船摆动 6–8 s 一周期——“烛光沿着黄铜刻痕移动”由灯的摆动产生，不由摄影机产生。辅光为艉窗直棂透入的暮色蓝（P03），在舱壁上形成竖条。罗盘口沿是画面最亮的线（P11）。

**LOC_DECK 甲板与海（`sea_deck`）**：V1 前段为暮色——太阳已落，天顶 P01，地平线残留一线极淡暖（不超过 P21 的 30% 饱和）；积云顶部仍有最后一点余晖。夜间以月光为唯一主光，硬、单向，从画右上方来；船灯在艉部，为人物脸部提供低位暖光。远岸灯光为 P13 小点（M7），始终在画左（家的方向）。

**LOC_HOME 旧日家中（`old_home`）**：室内主光为桌上蜡烛（燃烧状态 A→D，见 PROP_CANDLE），从低位照亮下半张脸与碗；月光从冰裂纹窗格斜入，在桌面、墙面与她的肩上投下裂纹状的影（与瓷片裂纹呼应）。脸部永远处于以下之一：烛光侧逆、窗格影中、玻璃反射中、焦外。屋檐外景：月光 + 门口壁龛里的小油灯；雨夜（CH3）时，雨丝只在小灯与月光的逆光中可见。

**LOC_PIER 候船处（`pier_waiting`）**：棚下一排搪瓷灯罩白炽灯 2400K，形成离散光池；人群在光池之间穿行，明暗交替；棚外是蓝调时刻到夜的海，轮船舷窗一排暖点。盖章柜台的玻璃隔板上反射灯泡。湿木板反光（刚下过雨）。

**LOC_HARBOR 港口时代更替（`harbor_eras`）**：固定机位，**所有时代统一为同一个暮色时刻、同一光线方向**（落日在画右后方已落下，天空余光从画右来）——这是让时代更替只表现为“建筑、旗帜、制服、船”的关键。每个时代的人工光不同：火把与灯笼（E1）→ 煤气 / 煤油路灯（E2）→ 白炽路灯（E3）→ 钠灯黄（E4，压低饱和）→ LED 白（E5）。

**LOC_MAPOFFICE 地图办公室（`map_office`）**：一盏黄铜底座煤油灯 2200K 放在桌面画右，玻璃灯罩；窗为百叶板，月光被切成平行条纹落在地图与手上——“分割”的光。反差全片最高。

**LOC_CHAPEL 礼拜堂（`chapel`）**：BR2 前段为日落前最后 15 分钟——低角度的太阳从西侧尖拱彩窗射入，在地面陶砖、长椅、母亲浅色衣料与肩上投下“千万瓣”柔彩；空气中有极淡的尘（不做烟雾机式的浓雾，只在光路里看得见）。随后进入蓝调时刻：彩窗光瓣褪去，室内转为 P03 冷蓝，只剩侧坛几支蜡烛的暖点。母亲肩上的光瓣是本段最重要的光，摄影机降下时要让光瓣恰好落在她肩上。

**LOC_WINDOW 窗边（`night_window`）**：东端三面窗湾。夜间：手机屏幕 6500K 照亮夜班员工的下半张脸；窗外港口灯与远处起重机的航空灯为背景点光；修复师带来的茶在暖色小台灯（窗湾角落的一盏 2700K 阅读灯，原本开着）下冒热气。黎明：窗光成为主光，按 §2.3 渐变；茶杯热气必须**以暗背景衬托、以窗光逆光照亮**（摄影机位置使热气背后是窗框暗部或尚暗的海面，而不是最亮的天空）。

**LOC_CORRIDOR 长廊（`corridor`）**：见 §7.11。月光从南侧（摄影机右后方）十一个拱窗斜入，每 4 m 一个拱形光斑，构成“光的节拍”；每面主展柜内的时代保留自己的光源与色温。

### 3.5 光线承担转场的方式

1. **光点接光点**：远岸一点灯（GAP1）→ 修复台灯在瓷釉上的高光点（PRE1），同一画面位置、同一大小，色温从 1900K 经调色过渡到 3500K。
2. **格栅影接裂纹**：冰裂纹窗格影在桌面上移动 → 瓷片的裂纹（PRE1）。
3. **扫过的光**：手电筒扫过展柜（INTRO 背景 / INTERLUDE）→ 船灯摆动的光扫过舱壁。
4. **光斑擦除**：港口固定机位中，一片云影或一艘船的影子横扫画面，影子过后时代已更替（BR1）——光影擦除，而非变形。
5. **彩窗光瓣接屏幕冷光**：母亲肩上的光瓣褪去（蓝调）→ 夜班员工背上的手机冷光（BR2）。
6. **月光节拍**：长廊中每个月光斑对应约半小节，摄影机穿过光斑的节奏与音乐同步（CH3）。
7. **夜到晨**：同一扇窗、同一机位，光由冷变暖（OUTRO / TAIL），不剪辑。

## 4. 摄影语言

### 4.1 画幅与机器

- 画幅【锁】：2.39:1 宽银幕，交付 1920×1080 内含 1920×804 有效画面（上下黑边），24 fps，6164 帧。
- 获取方式：2× 变形镜头（anamorphic）+ 4:3 传感器区域（如 ARRI ALEXA 35 或同级），以获得椭圆焦外、柔和的边缘衰减与真实的变形镜头质感。AI 生成提示词统一写“anamorphic 2.39:1, 35mm film look”。
- 镜头光晕（flare）：只允许暖色、短、低强度的水平光晕（船灯、烛火、黎明地平线），**禁止蓝色长条形光晕**。

### 4.2 镜头组

| 焦段（变形镜头实际焦段） | 用途 | 典型镜头 |

| 50 mm | 双人中景（窗边）、中景人物关系 | 第八章“安静的双人中景” |
| 75 mm | 中近景、隔玻璃的脸、背影对接 | 母亲背影 ↔ 夜班员工背影 |
| 100 mm | 近景脸、手、眼睛 | 航海人迷茫的眼睛、两只手分开 |

选择原则：越接近人物情感核心，焦段越长、运动越少；越需要“天地”，焦段越短、运动越慢越稳。

### 4.3 摄影机支撑

| 支撑 | 何时使用 | 规则 |
|---|---|---|
| 轨道车 + 稳定遥控头 | 稳定横移、长廊主运动、展柜前横移 | 速度恒定，起停有 12–24 帧的缓入缓出 |
| 滑轨（slider，1–1.5 m） | 微距与特写的缓慢推进 / 横移 | 速度极慢（≤ 2 cm/s），配合焦点转移 |
| 摇臂 / 伸缩摇臂（techno-crane） | 航海人视线“走出船舱”升到海面；礼拜堂从高处缓慢降下 | 一次完整运动，不做多次加速；降下全程 ≥ 6 s |
| 重载航拍 | 海上极远景、港口全景 | 只用于缓慢、高、稳的运动，**禁止“航拍感”的快速掠过** |
| 运动控制（motion control） | 港口时代更替（固定机位多次重复）、长廊主运动（玻璃内合成需要可重复路径）、开场与未来展柜的同一机位 | 必须保存机位数据，供“同机位”镜头复用 |
| 三脚架锁定 | 港口时代更替、尾声茶杯 | 尾声最后一个镜头完全锁定，不加任何数字推进 |
| 手持 | **仅限**：候船处人群与告别（V2）、甲板风中（V1 局部）、CH3 披衣瞬间 | 呼吸式的“自然手持”，幅度小；不得晃动、不得模拟纪录片抖动 |

### 4.4 运动词汇（只用这五种）

1. **缓慢推进**：情绪的累积。速度让观众“几乎察觉不到”，例如 5 s 内推进 30 cm。
2. **稳定横移**：时代并置。展柜前、长廊、候船处；横移方向在整片中保持“从画左到画右”（从过去走向明天）。
3. **焦点转移**：从玻璃表面到玻璃中的另一个时代；从手到脸；从杯子到窗外。转焦时长 ≥ 1 拍（0.79 s）。
4. **少量自然手持**：仅限 §4.3 所列。
5. **有意义的慢动作**：仅用于以下“不可逆的瞬间”——

| 事件 | 帧率 | 段落 |
|---|---|---|
| 风掀起海图纸角 | 48 fps | V1 |
| 旧衫被抖开、落入藤箱 | 48 fps | V2 |
| 印章落下 | 96 fps | V2 123.3–126.2 |
| 两只手分开，其中一只留在原位 | 48 fps | V2 130.4–135.4 |
| 第一滴雨落进碗心 | 96 fps | CH3 |
| 航海人把外衣披到同伴身上（衣料落下） | 48 fps | CH3 |

### 4.5 构图与屏幕方向

- 屏幕方向【锁】：画左 = 家 / 过去 / 回望；画右 = 远方 / 未知 / 明天。航海人望岸灯 → 看向画左；迁徙女性登船 → 走向画右，回头望画左；黎明 → 从画右亮起。
- 横移方向：全片横移默认从画左到画右。
- 匹配剪辑登记：每一组匹配剪辑必须记录主体在画面中的位置（以 2.39:1 有效画面为 0–1 坐标）与大小，容差 ±3%。例：开场两手中心 (0.50, 0.55)，手宽占画面高 45%。
- 宏大远景中人物的位置：人物在画面面积中不超过 2%，但必须处于月光或灯光中（“人物在天地间很小”，但不能找不到）。
- 双人镜头：窗边两人始终保持“他靠窗（画右）、她在他身旁（画左）”的站位关系；她从画左走入并坐下。

### 4.6 微距规则

1. 只拍简报列出的质感：黄铜氧化、瓷器釉光、纸张纤维、海盐、棉布折痕、雨滴、玻璃倒影、茶杯热气。
2. 每个微距必须有动机：有人在看、在触碰，或紧接人物的视线。
3. 每个微距画面必须保留一个可辨认的边缘（碗沿、罗盘口沿、袖口线），让观众知道“这是什么”。
4. 景深：微距用 T5.6–T8，必要时做焦点叠加；禁止“AI 微距”的塑料感超锐与过度饱和。
5. 罗盘针微距的“稳定”：针在静止前做 2–3 次极小的摆动后停住，停住的一刻对准歌词“认得南”（49.11–49.99）。

### 4.7 胶片质感

- 基础：35mm 负片质感。夜内景参考 500T 感光度的颗粒，日落 / 黎明外景参考 250D。颗粒细腻、有机，随亮度变化（暗部颗粒更明显）。
- 光晕（halation）：只在强点光源周围出现极细的红橙光晕（半径约画面宽度 0.15%），强度按 §2.4。
- 高光：柔和滚降，烛焰与灯泡中心可以接近溢出，但周围必须保留层次。
- 暗部：抬起 2–3% 的黑位，保留层次（P28）。
- 锐度：不过度锐化；皮肤、布料纹理靠光而不靠锐化。
- 禁止：数字噪点、HDR 光晕、过度清晰、塑料感、抖动的 AI 闪烁。

### 4.8 AI 生成的摄影机描述规范

每个镜头提示词必须依次写明：景别 → 焦段与镜头类型（“40mm anamorphic”）→ 摄影机高度与角度 → 运动（五种之一，含速度）→ 焦点 → 光源（来源 + 色温 + 方向）→ 色板 id → 质感（“35mm film grain, subtle halation”）→ 帧率（若为慢动作）。人物、道具、场景一律引用参考图（`CHAR_* / PROP_* / LOC_*`），不重新描述可能冲突的外貌。

## 6. 道具设定

道具双状态原则：凡在博物馆中出现的历史物件，都有“**当年**”（使用中）与“**博物馆**”（今天）两个状态。两状态的形状、尺寸、纹样必须完全一致，差异只来自老化。以下尺寸为实物尺寸，供道具组制作与 AI 生成比例参考。

### 6.1 CHART 海图（针路图）｜ `PROP_CHART`

- **形制**：横向长卷，高 32 cm，全长约 210 cm（画面中通常只展开 60 cm）。皮纸（桑皮纸）本，托一层棉纸。
- **画面内容**：以“山形”立面画法描绘一段虚构海岸线（与 PROP_MAP 是同一段海岸，见下）——岛屿画成小小的山的侧影，礁石为墨点，水面以极淡的花青（`#6E8AA0`）晕染，陆地为淡赭（`#B49A6E`）；一条细墨点线标出航路，沿线有小楷注记（**不可读**：离焦、掠射角或由书法顾问写真实的针路用语）。
- **当年状态**（船舱）：纸色 `#DCCDA6`，已被手翻软，四角卷起；被两块小铜镇纸与一块圆石压住；有一处烛泪。风从艉窗进来时，右下角被掀起（V1，48 fps）。
- **博物馆状态**（展厅平柜 G2）：纸色泛黄 `#CDB98C`，满布褐色霉斑（foxing，`#A8875A`）；边缘缺损处已用调色和纸修补，补纸颜色略浅；平放在倾斜 10° 的无酸卡板上，用两条透明亚克力压条固定。
- **匹配剪辑锁**【锁】：博物馆亚克力压条的位置 = 船舱铜镇纸的位置；两者都以 90° 正俯拍、同一段海岸线、同一裁切（一座双峰小岛位于画面 0.62, 0.40）。

### 6.2 COMPASS 黄铜罗盘 ｜ `PROP_COMPASS`

- **形制**：圆形黄铜罗盘，外径 15 cm，厚 3.2 cm；底座为一只方形樟木罗盘匣（19 × 19 × 5 cm，匣内凹槽托住罗盘）。中央针池直径 4.2 cm，上覆一片薄云母（微带金色、可见层状纹理）。
- **针**：发蓝钢针，长 3.6 cm，以细铜针轴支起（旱罗盘）。【锁】**指南的一端点有一滴朱红漆（P16）**——“那根针认得南”：红端稳定指向“午”位。
- **盘面同心圈（由内到外）**：
  1. 针池外第一圈：八卦卦象（以刻线表示，无文字）。
  2. 第二圈：**二十四向**，顺时针自正北起为：子、癸、丑、艮、寅、甲、卯、乙、辰、巽、巳、丙、午、丁、未、坤、申、庚、酉、辛、戌、乾、亥、壬。刻字为小楷阴刻，字口填黑（字必须正确，微距中可读）。
  3. 最外圈：“星辰”——**二十八处小星点**（直径约 1 mm 的钻孔小圆），以极细刻线连成小星组；正北“子”位上方一颗较大的星点嵌银（北辰）。——“有人把星辰刻进黄铜的圆盘”。
- **当年状态**（船舱）：铜色温暖 `#B8925A`，口沿“午”位附近被拇指磨得发亮（P11）；刻槽里积着烟灰与油污（`#4A3A28`）；铰合处与匣边有白色细盐霜。云母完整。
- **博物馆状态**（展厅 G1 罗盘柜）：经稳定化处理，哑光低反射；包浆呈巧克力褐 `#6E5536`，高点保留蜂蜜色 P09；最深的刻槽与针轴周围有铜绿斑（P12）；【锁】**云母片在“乾”位边缘有一道裂纹**（时间的痕迹——当年完整）；针轻微锈蚀，静止时仍指南。置于透明亚克力托架上，倾斜 15°，下衬近黑深蓝绒布（`#101A2A`）。
- **光线**：船舱中摆动的灯光让光点沿二十四向刻字依次移动（V1 35–40“有人把星辰刻进黄铜的圆盘”）。

### 6.3 BOWL 青花碗（整碗）｜ `PROP_BOWL` 与 SHARDS 青花残片 ｜ `PROP_SHARDS`

**唯一标准纹样【锁】（所有时代、所有残片、所有 AI 生成必须一致）**：

- **器型**：南方民窑撇口碗（口沿微外翻）。口径 15.2 cm，高 6.6 cm，圈足径 6.0 cm，足高 0.8 cm，壁厚约 3 mm。手拉坯，略不圆。
- **釉**：白中泛极淡青（`#EDF1EF`），积釉处更青（`#E3EAEC`），有细小棕眼（针孔）；光泽温润，不是镜面。
- **钴料**：青花蓝 P07 `#2B4A8B`，笔触快、不工整，有晕散；钴料堆积处出现深色铁锈斑点 P08 `#18294F`。
- **外口沿纹带**（“春色还留在碗沿”）：口沿下 1.0 cm 宽的纹带，上下各一道细弦线；带内为**一枝连绵不断的折枝梅**，共 16 朵五瓣梅花，盛开与花苞交替，每朵约 6 mm。
- **外壁主纹（两面）**：
  - A 面：一叶单帆小船，帆上三道横线（竹篾），船下三行波浪线；船的左上方一弯新月。
  - B 面：一段矮篱笆、一枝梅、一扇方窗，窗内画**冰裂纹格子**（与旧日家中窗格同一图案）。
  - A 与 B 之间：大面积留白（白釉，无纹）。
- **内壁**：口沿内一道细弦线；**碗心**为双圈（直径 4.5 cm）内一朵五瓣梅花，花心钴料积色最深。
- **圈足**：无釉，露胎处有“火石红”橙褐色（`#B9784A`），粘少量窑砂；**底部无款**（避免文字）。

**当年状态**（旧日家中）：完整、釉光新鲜；盛着一碗白米饭——饭已凉，表面米粒发干、半透明，【锁】**没有一丝热气**；一双竹筷横放在碗口未动。另一状态：空碗放在屋檐下的石阶上接雨，碗心的梅花露出来；CH3 第一滴雨正落在碗心梅花上（96 fps）。

**博物馆状态 / 残片**（修复室）：碎成 **7 片 + 1 处缺失**——
- 残片 A（最大）：包含碗心梅花与圈足。
- 残片 B、C、D：口沿纹带分在三片上，【锁】**裂纹只从梅花与梅花之间穿过，没有一朵梅花被裂开**——对齐后口沿纹样完整连续（“碗沿的花纹依然完整”）。
- 残片 E：A 面小船与新月（完整）。
- 残片 F：B 面窗与冰裂纹（完整）。
- 残片 G：一片小残片，带部分波浪线。
- 【锁】**缺失处**：位于 A 面与 B 面之间的留白区域、约 2.5 × 3 cm——“出发”与“家”之间的那一块永远找不到（留白）。
- 修复中状态：残片放在灰色海绵垫上；已粘合的部分插在修复用沙盘里固定，等待胶干。断面为灰白胎，边缘略有磨损与旧污。

### 6.4 PATCH 袖口补丁 ｜ `PROP_PATCH`

- 位于航海人靛蓝短褂【锁】**右袖口内侧**（袖口折边的里层），翻开才可见。
- 尺寸 4.5 × 6 cm 的长方形，浅蓝手织平纹棉布 `#7D9CBB`——**与等待的人的短袄是同一块布**；布比短褂的布略厚。
- 针脚：本白棉线（`#E9E4D6`），细密的平针，每针约 3 mm；一角的针脚明显不齐，有一个打了两次的小结（她补的时候笑了一下、手抖了）。
- 老化：被他的指腹反复摩挲，中间部分已经起毛、发亮、颜色更浅。
- 出现：V1 50–53（第一次揭示）；V2 118 插入（她在补这块布时羞涩地笑——我们看到针、顶针、浅蓝布和她的银镯）；CH2 145–147（先摸补丁再看岸灯）；CH3（披衣后下意识摸袖口）。

## 7. 场景设定

### 7.0 总平面：一座建筑，几个时代

博物馆是一座虚构的旧海关关栈（约 1880s–90s 建成）改建而成，坐落在港口水边。**同一座建筑在“港口时代更替”中以更早的样子出现**（导演备注 §2）。

- **朝向**：长轴东西向，长 64 m、进深 22 m；**南立面临码头与港湾**，港口出海口在东南。月光从南侧进入；黎明从东端到来（画右）。
- **结构与材料**：花岗岩基座与勒脚（`#8F8C86`）；红砖墙（`#7A4B3A`），局部石灰抹面已斑驳（`#A9A296`）；室内两排铸铁柱（深灰绿漆 `#3B4540`）；上层为柚木地板；木桁架屋顶；南侧上层为一条拱券外廊（原为开敞外廊，改建时以玻璃封闭）。
- **一层**：西端门厅；中部原仓库大厅（今为库房）；**东南角修复室**（`restoration_lab`）——即 1890s 的港务测绘办公室（`map_office`），**同一个房间、同一扇拱窗、同一片港口**：一张桌子上，有人画线；一百多年后，同一扇窗下，有人修补裂纹。
- **二层**：北侧为主展厅（`museum_gallery`）；南侧为封闭外廊——**长廊**（`corridor`）；长廊东端为三面窗湾——**窗边**（`night_window`）；长廊北墙东端有一扇小门通员工茶水间（热水壶、茶叶罐）。
- 展厅与长廊之间有五个拱形门洞，月光经长廊拱窗、再经门洞斜入展厅。

### 7.1 LOC_GALLERY 展厅 ｜ `museum_gallery` ｜ `modern`

- **尺度**：30 × 14 m，净高 6 m；两排各 6 根铸铁柱，柱距 4.5 m；柚木地板（`#5E4430`，打蜡后有柔和反光，能接住月光斑）；砖墙局部露出。
- **展品布局**（摄影地理）：
  - **G1 罗盘柜**：展厅中部偏南、正对第三个门洞的独立展台。台座高 95 cm（深色木 `#2A2622`），玻璃罩 60 × 60 × 50 cm（低铁超白玻璃、无框）；罗盘置于 15° 透明托架，高约 1.10 m；柜内衬近黑深蓝绒布 `#101A2A`；顶部一盏 3000K 窄角射灯。【锁】开场机位：摄影机在 G1 南侧玻璃面正前方，镜头高 1.18 m，100 mm 微距起幅，缓慢后退至 75 mm 中近景范围（运动控制记录，CH4 复用）。**未来变体**：同一展台、同一玻璃罩，罗盘换成平躺的深灰外套（PROP_COAT 未来状态）。
  - **G2 海图平柜**：G1 东侧 1.5 m，高 90 cm 的平面展柜，玻璃面水平；海图倾斜 10° 平放。V1 开头的 90° 俯拍匹配剪辑在此。
  - **G3 三联立柜**：北墙一排三个通高立柜（各 1.4 m 宽 × 2.4 m 高 × 0.7 m 深），从西到东（画左到画右，过去到较近）：G3a 航海（针路簿、测深铅锤）、G3b 家用器（一个**空着的托架**——留给正在修复的青花碗——以及其他残瓷）、G3c 迁徙（打开的藤箱、叠好的旧衫、木梳与包布、通行纸）。CH1B 86.9–89.9“多少不敢说的爱 借月色流传”的横移经过这三面柜：G3a 玻璃中映着船舱，G3b 映着旧日家中，G3c 映着候船处——反射源在物理上是摄影机身后、南侧月光照亮的门洞。
- **夜间照明**：展柜 3000K 调暗；顶部轨道灯全关；只在地脚有 4000K 极暗的走道灯；月光从门洞成束斜入。
- **声音氛围**（供表演与剪辑节奏参考；成片声轨以原曲为准）：空调低鸣、远处海浪、木地板偶尔的一声轻响、夜班员工很远的脚步。

## 8. 跨时代转场语法

### 8.1 五种合法的“真实细节”

简报：“所有跨年代转场由真实细节引出：手势、反射、光线、衣料运动与相似构图。”因此全片只有五种跨时代转场，每一次都必须在分镜表 `transition_in.on` 中写明“匹配的是什么”。

| 类型 | `transition_in.type` | 规则 |
|---|---|---|
| **手势** | `match_cut` | 动作在 A 镜头中开始、在 B 镜头中完成；剪辑点在动作的中段（不是开始或结束）；手的位置、方向、速度一致（容差 ±3% 画面） |
| **反射** | `reflection` | 另一个时代出现在玻璃中，由摄影机角度或焦点转移带出；遵守反射物理（§8.3）；不得使用无来源的“幽灵叠影” |
| **光线** | `light` | 光点接光点、格栅影接裂纹、光影擦除；色温在 12–24 帧内经调色过渡 |
| **衣料运动** | `match_cut` | 布料的展开、落下、压平的动作跨越剪辑点；布的运动方向一致；可用 48 fps |
| **相似构图** | `match_cut` | 主体的形状、位置、大小相同（如碗沿的圆、地图的线、门槛的线）；记录坐标 |

叠化（`dissolve`）只允许作为以上五种的辅助，长度 12–36 帧，且必须有光线或反射作为动机；`fade_in` 只用于开场第一帧之前（如需要）。

### 8.2 禁止

1. 禁止 AI 变形（morph）、液化、人脸互相融化、物体“长”成另一个物体。
2. 禁止无动机的叠化、闪白、光效转场、旋转 / 缩放转场、数字推拉造成的假运动。
3. 禁止半透明“鬼魂”人物站在当下空间里——过去的人只存在于玻璃反射、焦外或他们自己的时代中。
4. 禁止为了转场而改变人物面貌、道具纹样、光源方向。

### 8.3 反射物理规则（M2 的技术基础）

1. 玻璃反射率约 4%（正对）到 25%+（掠射角 > 70°）。**另一个时代要被看清，必须：玻璃后（柜内）暗，且被反射的空间亮。** 所以所有“时代之窗”展柜内衬近黑深蓝绒布，柜内照明调到最低。
2. 反射中的空间位于“镜像深度”：对焦距离 = 摄影机到玻璃的距离 + 被反射物到玻璃的距离。因此“从玻璃表面的指纹 / 雾气转焦到反射深处的船灯”是物理上真实的焦点转移，可作为转场手段。
3. 反射随摄影机角度改变而显隐：INTRO 中“随着摄影机角度改变，海面隐去，展柜里只剩一枚黄铜罗盘”必须通过真实的角度变化实现（摄影机后退并略向右绕行约 15°），而不是淡出。
4. 反射中的画面是镜像的：反射中的人物、船、文字（如有）左右相反；合成时必须做镜像，屏幕方向规则按反射前的真实空间计算。
5. 反射的颜色会被玻璃轻微染绿——使用低铁超白玻璃，反射色保持中性。
6. 修复师自己的倒影永远存在于玻璃中（物理上必然）；在需要“另一个时代”占据玻璃时，她的倒影应较暗、或处于另一深度的焦外。

### 8.4 匹配剪辑登记规范

每一组匹配剪辑在分镜表中记录：A/B 镜头 id、主体、画面坐标（0–1，以 2.39:1 有效画面为准）、主体大小（占画面高度百分比）、方向 / 运动、剪辑点所在的动作阶段。B 镜头的生成提示词必须引用 A 镜头的末帧作为构图参考。

### 8.6 剪辑节奏总则

- 剪辑点优先落在 `beats.json` 的节拍或演唱换气处；重要的眼神与动作至少保留 2 拍（约 1.6 s）。

- 段落之间的“呼吸”：GAP1（53–56）、CH1 末全乐队骤停（95.95–96.85）、BR1 回落（162.75 起，164.25–165.6 近乎无声）、CH4 全乐队骤停（229.1–230.5）——这些地方画面应停住或极慢，不塞剪辑（v1.1 按实测能量修订：间奏 102.0–103.4 与 CH4 232–233.4 并非静默；CH3 在 214.25 之前是回落的副歌，214.25–229 才是全曲最强；尾奏 245.9–249.3 是全曲最响的一段，安静段为 249.3–252.4）。

## 10. 敏感性准则

1. **虚构的城市与机构**：城市、博物馆、礼拜堂、航运公司、港务机构全部虚构；画面中不出现任何真实机构名称、标志、品牌（包括手机、茶叶、手套、胶粘剂的品牌）。
2. **虚构的旗帜与徽章**：所有旗帜、帽徽、胸章为中性虚构设计（§7.7），定稿前须做相似性审查；旗帜永不作为画面主体或特写；不出现任何真实或历史上的国旗、军旗、政党旗、殖民旗。
3. **殖民历史**：以“一只手、一条线、一道关”抽象表现权力对普通人的分割；不点名、不妖魔化任何民族或国家；不展示暴力；把重量落在“等待通行的人”身上，而不是落在施加者的形象上。
4. **迁徙**：迁徙女性是有自己选择与尊严的人，不是苦难奇观；不使用“苦力贸易”、贩卖人口、乞讨等刻板影像；候船人群中有家庭、学生、工人、老人，衣着整洁而朴素；不把“南洋”异域化。
5. **宗教**：礼拜堂是真实的敬拜场所，以安静、敬重的态度拍摄；母亲的祈祷不被解释、不被评判；不表现改宗、宗教冲突或任何宗派的优劣；不特写具体宗派标识与圣像，彩窗为非具象图案；其他在场者同样安静、受尊重。航海人的船上若出现航海信仰的小龛，只作焦外背景，不作道具化处理。
6. **自然肤色**：不美白、不磨皮；不使用“亚洲题材黄绿滤镜”；不同人物保持真实的肤色差异；本地老人等人物以尊严呈现，不作“他者”的点缀。
7. **避免东方主义陈词**：不堆砌红灯笼、龙、锣、旗袍特写、香火烟雾等符号；所有民俗细节必须服务于人物，而不是“装饰东方”。
8. **儿童**：孩子只出现一双小脚；拍摄遵守未成年人保护规定（短时段、监护人在场、温暖场地）。
9. **真实人物**：不模仿任何真实人物的样貌；AI 生成时不得使用真实名人或可识别个人作为参考。
10. **情绪伦理**：不煽情——无人哭泣特写、无配乐以外的煽情手段；治愈来自陪伴而不是被拯救；夜班员工不被塑造成“可怜的老人”，他是一个有自己生活、正在犹豫的人。

## 12. AI 生成通用规范

1. **参考先行**：先生成并锁定全部 `CHAR_*`（转面 + 手 + 服装细节）、`PROP_*`（多角度 + 微距 + 双状态）、`LOC_*`（主机位全景 + 关键机位）参考图；所有单镜头生成必须以这些图作为图像参考。提示词见 `bible.json` 的 `ref_prompt_en / ref_prompt_zh`。
2. **手**：手的特写是本片的核心——每个主要人物单独生成手部参考（掌心、手背、侧面、关键动作），生成后逐帧检查手指数量与关节；有问题的镜头优先以实拍或手部替身补拍。
3. **一致性**：同一人物在不同镜头中只用同一套参考图与同一组面貌关键词；不在单镜头提示词中重新描述可能冲突的外貌。
4. **文字**：负面提示词中始终包含“文字、字母、水印、标志”；需要文字的道具以实拍或后期贴图完成。
5. **物理**：烛焰、热气、雨滴、布料、海浪必须物理可信；检查火焰方向与风向一致、热气向上、反射镜像正确。
6. **全局负面提示词**：见 `bible.json` 的 `negative_prompt_global_en / negative_prompt_global_zh`。各镜头可在此基础上追加。
