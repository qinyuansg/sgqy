## 预演如何重新渲染

```bash
cd previz && npm install                       # three.js r169 + playwright（已装 Chromium）
node tools/bake_cast.mjs                       # 生成人物几何缓存（约 6 分钟，缓存不入 git）
node render.mjs --shots S066 --u 0.1,0.5,0.9 --stills out/check   # 单镜静帧
node tools/render_parallel.mjs --jobs 2 --w 1280 --out out/film/previz_raw.mp4   # 全片（可续渲）
tools/finish.sh out/film/previz_raw.mp4 out/film/countless_tonights_previz       # 遮幅 + 原曲 + 审片版字幕
python3 tools/survey.py out/survey 960         # 每镜首/中/尾帧 + 每个剪辑点前后帧对照
```
原曲文件放在 `audio/song.mp3`（不入 git）。

## 从预演到正片

1. 用 `delivery/prompt_pack_zh_en.md` §5 的参考库提示词生成并锁定人物、道具、场景参考图（连戏锁：修复师左袖口磨损、航海人右袖口内侧补丁、妻子左腕银镯、碗沿折枝梅等）。
2. 按每镜的关键帧提示词 + 参考图生成首帧（匹配剪辑镜头同时生成尾帧），再用运动提示词做图生视频；超过约 8 秒的镜头按 `segments` 分段。
3. 玻璃反射、跨时代叠映镜头按 `plates` 分层生成后合成（导演裁定：时代影像按画面所见合成；当下的倒影为真实镜像）。
4. 以 `shotlist/shots.json` 的帧级时码对齐原曲剪辑；预演成片即为剪辑参考。
