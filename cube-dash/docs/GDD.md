## 0. 一句话概述

故障病毒让方块星系里的方块变红、变凶。小蓝（Blu）在漂浮于云海和星环之间的糖果科幻竞技场上走位，**引红方块互相撞上（咚！眼冒金星），再一冲把它们撞碎**，变回会欢呼、会飞回家的开心小方块（解救！）。

源原型里，红方块追着玩家会自然"抱团"。本设计把这个抱团现象做成了核心技巧：敌人就是你的武器。

## 1. 设计支柱

| # | 支柱 | 含义 | 验收标准 |
|---|---|---|---|
| 1 | 敌人就是你的武器 | 红方块互撞、台球推开、炸弹、激光都能拿来对付敌人 | 大部分解救来自玩家主动制造的碰撞 |
| 2 | 10 秒上手，100 小时精通 | 只有 3 个动作键，只有 4 条规则 | 新玩家 10 秒内完成第一次"解救" |
| 3 | 手感第一 | 每个动作都有独立的顿帧、震屏、粒子、音效和震动 | 关掉 HUD 也能凭手感判断发生了什么 |
| 4 | 糖果科幻，一眼看懂 | 蓝色=你，红色=敌人，黄白/橙色条纹=危险，黄星=可以冲，金色=奖励 | 画面转灰度后仍能分辨敌我（靠轮廓、眉毛、描边） |
| 5 | 善意设计，不坑 | 不收钱、无体力墙、不掉段、不做连续签到、抽奖全透明 | 家长中心的四项承诺全部成立 |

### 四条核心规则（引擎级不变量，任何敌人和模式都不能破例）

1. 红方块碰到你，扣 1 颗 ♥ —— **冲刺中永远无敌**。
2. 方块撞在一起（撞队友、撞墙、被推飞的方块砸到、被冲冲撞、被炸、被激光扫到），就会 ⭐ 眩晕。
3. 冲向头上有 ⭐ 的方块，就把它**解救**！
4. 快被撞到的一瞬间冲刺，就是**完美！**

推论：有 ⭐ 的方块永远无害；冲向普通方块会把它像台球一样推飞，所以每一次冲刺都有用。暂停菜单用 4 张无字图示展示这四条规则。

## 2. 源游戏 DNA 对照（用户原型 → 最终设计）

| 源原型元素 | 最终设计中的形态 |
|---|---|
| 蓝色方块主角，WASD / 方向键移动 | 小蓝：大眼睛、腮红、小手小脚（海报造型）；移动带惯性手感（加速 60、减速 40 u/s²） |
| 10 个红方块随机生成，尺寸 20–60 px | 怒怒方分小、中、大三种（0.7 / 1.0 / 1.4 u）；第 1 世界同屏上限正好是 **10** 个 |
| 速度 = 随机 × 80 px/s，追向玩家中心 | 带惯性和转向速度上限的追踪 AI；越大越慢（3.8 / 3.0 / 2.3 u/s），小蓝永远跑得过它们 |
| 伤害 floor(size/4) | 所有伤害统一为 1♥（孩子可预测）；尺寸差异改为**击退距离**（大方块撞得更远） |
| 红方块自然抱团 | 核心玩法：引它们互撞 → 咚 → 眩晕 → 一冲穿透连碎 |
| HP 100，受伤后有无敌时间（原型中变灰） | 5 颗心；受伤后 1.5 秒无敌，小蓝以 6 Hz 脉动闪烁（不是变灰） |
| HP 条绿（>60%）、黄（20–60%）、红（<20%） | 心形血条下方的细条保留绿→黄→红三色（致敬原型）；剩 1 心时粉色心跳暗角 |
| Shift 冲刺，体力 100，绿色体力条 | Shift / 空格冲刺，⚡体力 100 按格显示（小蓝 4 格），脚下体力环 + 左上 ⚡ 条（海报样式，黄/青色，避开红绿色弱冲突） |
| 体力归零锁定 3000 ms | "累了"状态 1.3 秒，移速不减；小蓝冒汗喘气，按冲刺会"噗"一声并抖动体力格；辅助模式没有"累了" |
| 按住 Shift 持续冲刺 | 冲刺后继续按住 = 疾跑（1.35 倍速，每秒耗 30 体力），保留但不强制教学 |
| 游戏结束，按 R 重开 | 失败界面写"哎呀！"，按 R 或点"再来一次"，1.5 秒内回到游戏 |

海报元素全部落地：标题 LOGO（白色胖字 + 深蓝描边立体感 + 蓝色胶囊副标）、标语、沙色圆形竞技场、绿色方块围边、彩虹、浮空方块岛、云海、闪光。海报的三个卖点——灵巧走位、冲刺突围、追逐生存——正是规则 2、3、1。

## 6. 核心机制细则

单位：1 u = 小蓝的边长。

### 6.1 移动
- 最高速度 6.5 u/s（因英雄而异），加速 60 u/s²，松手减速 40 u/s²（一点点滑，显得有重量）。
- 以 70% 以上速度急转超过 120° 时触发 0.08 秒急刹：扬尘 + 压扁。
- 行走时小脚交替弹跳，身体向速度方向前倾；眼睛看向最近的威胁或 ⭐ 目标。

### 6.2 冲刺（冲得刚好）
- 第 0 帧立即生效，持续 0.18 秒，距离约 4 u，速度曲线 v(t)=v0·(1−t/T)^0.6；无敌 0.24 秒；输入缓冲 0.12 秒。
- 方向取摇杆方向；摇杆回中时冲向 5 u 内最近的 ⭐ 目标，没有就冲向面朝方向。
- **吸附辅助**：前方 ±25°（触屏 ±32°）锥形内若有 ⭐ 目标，冲刺自动修正对准它。只吸附可解救目标，绝不会把玩家吸进伤害。
- 冲向普通方块 = **推开**（6.4）；冲向 ⭐ 方块 = **解救**并**穿透**：每解救一只冲刺延长 0.05 秒（最多 +0.15 秒），返还 8 体力。
- 背对贴身方块冲刺逃跑时，不会误判为撞击（评审修复）。

### 6.3 体力 ⚡（掌握体力节奏）
- 上限 100（卡牌可加），冲刺消耗因英雄而异（小蓝 25 = 4 格）。
- 停止消耗 0.45 秒后开始回复，每秒 38。
- 归零进入"累了" 1.3 秒：不能冲刺，**移速不减**；体力环变灰并回充到 40%；小蓝冒汗喘气；按冲刺会"噗"一声、体力格抖动（让孩子知道为什么冲不出去）。
- 辅助模式没有"累了"。

### 6.4 台球推开（Knock）
- 冲刺碰到普通方块：方块沿冲刺方向以 13 u/s 飞出，摩擦 18 u/s²（约滑 4.7 u），飞行中是"弹射物"。
- 弹射物撞到其他方块（相对速度 ≥ 4）：双方咚、眩晕，被撞方以 0.7 倍速度继续弹出，最多连弹 4 次（卡牌可加）。
- 弹射物撞到围边 / 弹簧柱：单独咚。
- **保底**：小号 / 迷你方块被推开直接眩晕；附近 7 u 内没有其他红方块的"孤独方块"被推开也直接眩晕——还不会引怪的孩子永远不会卡住。
- 小蓝后弹 0.6 u，冲刺结束，不受伤。铁头推不动（麻薯除外），但每推一次 +1 裂痕。

### 6.5 咚！眩晕（Bonk → Dizzy）
- 触发：两个未眩晕方块接触，沿法线的相对速度 ≥ 3.0 u/s；或其中一方正在弹射 / 冲锋。
- 同一对方块 1.5 秒冷却；刚醒来的方块有 1.5 秒免疫。慢速挤在一起只会被轻推分开，不会咚——所以咚来自玩家引导的角度，规则可预测。
- 眩晕 3.0 秒：头顶 3 颗黄星**每秒消失 1 颗**（无数字倒计时），蚊香眼，身体变浅粉白、倾斜 15° 摇晃；最后 0.5 秒眉毛回来并抖动，提示快醒了。
- **所有"可解救"状态共用这一套外观**：眩晕、冲冲冲完累倒、激光方过热、铁头集满裂痕、Boss 核心暴露。

### 6.6 解救（Smash）
- 冲刺碰到 ⭐ 方块：顿帧、同色碎片、开心的马卡龙色小方块（绝不是蓝色，以免和小蓝混淆）弹出、转圈挥手、踩着星光飞走（约 1 秒），掉落水晶；1% 概率是金色方块。
- 1.5 秒内连续解救算连锁：音效按当前世界调式的五声音阶逐级上行，最多跨 2 个八度；场景里闪现"×3 连击!"。

### 6.7 完美冲刺（躲得漂亮）
- 判定：按下冲刺时，任一威胁的预计接触时间 TTC ≤ **0.30 秒**（辅助 0.45，小蓝被动再 +0.05），或间距 ≤ 0.5 u，或冲刺开始 0.12 秒内的无敌帧穿过了冲击环 / 激光 / 冲锋道。
- 效果：0.3 倍慢动作 0.5 秒（每秒最多触发一次，冲击波每次都有）；金色"完美!"印章 + 铃声；半径 3.5 u 冲击波使范围内方块眩晕；返还 40 体力；大招 +8。
- **"!" 提示**：威胁 TTC ≤ 判定窗口 + 0.2 秒时，小蓝头上弹出白色"!"并"叮"一声。按早了只是一次普通的安全冲刺，没有惩罚。

### 6.8 擦边（Near Miss，被动加分）
与方块擦身而过（间距 ≤ 0.6 u 且没被撞）：白色划痕闪光、左右声道"嗖"声、大招 +1、风格 +1。不教、不计入皇冠。

### 6.9 风格连击（STYLE）
擦边 +1、咚 +1、解救 +1、完美 +3；3 秒没有新动作就重置。10 / 25 / 50 / 100 分别弹出"不错! / 漂亮! / 帅呆了! / 银河传说!"，并提高分数倍率（×1.25 → ×2）和音乐层数。战役 HUD 不常驻显示连击数字，只在场景里瞬时弹出。

### 6.10 大招（NOVA）
- 充能只来自动作：解救 +3、咚 +1、完美 +8、擦边 +1、捡水晶 +0.5、每秒被动 +0.3；心数 ≤ 2 时 ×1.5（逆转机会），超载时刻 ×1.5。
- 充满：小蓝发金光，✦ 按钮脉动，响起英雄的三音动机。
- 释放：0.2 倍慢动作 1 秒，小蓝升空 + 闪光，然后按英雄不同：
  - **小蓝 · 大爆炸**：8 u 光壳，范围内方块按距离涟漪式解救（重型敌人眩晕 4 秒，Boss 眩晕并暴露核心）。
  - **麻薯 · 超大麻薯**：6 秒变成 2.5 倍大、无敌，碾过方块即解救，每 0.5 秒踩地震晕周围。
  - **闪闪 · 雷暴**：2.5 秒内 12 道闪电，优先劈 ⭐ 方块。
  - **星星 · 黑洞**：3 秒吸住 11 u 内所有方块（互相咚），然后内爆解救 4 u 内全部。

### 6.11 生命 ♥
- 小蓝初始 5 颗心（英雄不同：麻薯 7、闪闪 4、星星 5），辅助 +2，上限 10。
- 任何伤害都只扣 1 颗心；受伤后 1.5 秒无敌（6 Hz 脉动）、1.6 u 击退、110 ms 顿帧、心形碎裂动画。
- 解救掉心概率 4%（心数 ≤ 2 时 10%），上限 25%。
- **第二次机会**（每关一次，免费，无广告）：第一次心数归零时时间冻结，小蓝漂在泡泡里，按一下"再来一次!"即以 3 颗心、2 秒无敌复活，并放出 6 u 击退波。
- **检查点 🚩**：普通关卡中段到达检查点；失败后可"从 🚩 重来"，恢复当时的心数、卡牌和等级。

### 6.12 水晶与局内升级
- 解救掉落青色水晶（小 1 / 中 2 / 大 3 / 超大 6 经验），弹出后自动吸附（2.2 u，卡牌可加）。
- 经验满 → 升级：游戏**完全暂停、没有倒计时**，三选一卡牌（人生第一次只给 2 选 1；前两关有一张"推荐"卡弹跳）。卡片出现后 0.6 秒内的输入无效，防止乱按选错。
- 每关大约 3–4 次升级。

## 15. 新手引导（无字教学，10 秒内开玩）

- 标题画面：海报风格大 LOGO 叠在实时 3D 方块岛上，"点击任意处开始"。
- **第一次启动直接进入 1-1**：没有菜单、不起名字、语言按浏览器自动判断。
- 1-1「第一次相撞」的流程（小蓝在 1-1 不会掉到 1 心以下）：
  1. **移动**：一只慢速怒怒方从传送门出来，头顶显示当前输入设备的移动图示。
  2. **咚**：两只方块从相对方向追来，本关会互相靠拢，几秒内必然相撞 → ⭐ 出现 → 时间放慢，冲刺图示在它们头顶弹跳 → 冲刺！巨大的"解救!"印章，被救的方块对着镜头挥手。
  3. **推开**：两只睡觉的方块，冲向它们学会台球推开。
  4. **一圈方块**：一群小方块抱团，一推连咚，一冲穿透全部。
  5. **大招**：大招预先充满，按钮脉动，一大群方块涌来 → 释放 → 通关慢动作。
- 后续每关只教一件新事；新敌人第一次出现时配一张 2.5 秒的"NEW!"卡：剪影 + 弱点提示。
- **提示气泡**（只有图标，每 60 秒最多 1 次，每关最多 3 次，仅前两个世界或辅助模式）：45 秒没打出咚 → "两个方块相撞"图标；连续错过 ⭐ 方块 → ⚡→⭐ 图标；频繁"累了" → 数体力格图标；大招充满 20 秒没用 → 按钮弹跳；被同一种敌人打中 3 次 → 该敌人的"怎么打"卡片。

## 16. 难度与辅助

- **隐形守护**（只会变简单，绝不变难）：压力值 = 近 40 秒受击 ×2 + 心数 ≤ 2 时 +2 − 每次完美 0.5。压力 ≥ 4：追击令牌 −1、刷怪间隔 ×1.15、掉心 ×1.5；压力 ≥ 7：令牌 −2、刷怪 ×1.3、掉心 ×1.8、眩晕 +0.5 秒、敌人速度 ×0.9；20 秒没被打恢复一级。
- **小帮手模式**（暂停菜单随时切换，同一关失败 2 次时主动询问一次）：+2 心、敌人速度 ×0.8、完美窗口 0.45 秒、没有"累了"、更强的冲刺吸附、Boss 预警 ×1.3。**皇冠照样全部可拿**，分享海报上不显示使用了辅助。
- 容错：第二次机会、检查点 🚩、Boss 阶段检查点、Boss 失败降速、失败照拿金币和解救数、"哎呀!"而不是"游戏结束"。

## 17. 电影化演出与特效（糖果科幻）

- **色彩法则**：蓝 / 青 = 你；红 = 只用于敌人身体；黄白 / 橙色条纹 + "!" = 危险区域（最后 0.15 秒闪白）；黄星 + 浅粉白 = 可以冲；青色宝石 = 水晶；粉色 = 心；金 = 宝物 / 传说；马卡龙色 = 被救的朋友。**竞技场地面永远是亮色**，暗色世界只把天空变暗。
- **角色渲染**：圆角"黏土玩具"方块；脸部（大眼睛 + 高光、腮红、眉毛、嘴）由着色器程序化绘制，任意尺寸都清晰；所有敌人共享**一个**实例化网格（一次绘制调用）；实例化圆形接触阴影（任天堂式可读性），不使用阴影贴图。
- **后处理**：渲染 → 泛光（高阈值，只有自发光部分发光）→ 一个合成通道（暗角、粉色危险暗角、闪光、有上限的色差、调色）→ 输出。四档画质（极低 / 低 / 中 / 高）+ 自动降档。
- **镜头**：俯角约 55°，**永不旋转**；桌面端自动适配让整个竞技场可见；手机竖屏 / 横屏自动切换跟随模式（死区 + 前瞻，触屏时小蓝略低于中心）；创伤模型震屏；变焦冲击 ≤ 5%；冲刺 FOV 微踢。
- **过场**（所有过场 0.5 秒后可跳过）：关卡开场从太空俯冲穿云（首次 2.5 秒 / 重复 1.4 秒）、Boss 登场推镜 + 名牌、胜利环绕、失败推镜、大招拉远、阶段转换。
- **粒子**：同色方块碎片、星星爆、冲击环、尘土、传送门（地面光圈 + 天空光柱）、冲刺残影 + 拖尾、擦边划痕、完美金环、爆炸、闪电、黑洞漩涡、彩纸、被救方块升空星光——全部对象池 + 实例化，零帧内分配；小蓝 3 u 内的粒子半透明，敌人永远画在特效之上。
- **舒适与安全**：全屏闪光每秒最多 3 次（多余的改为边缘脉冲）；色差 ≤ 0.003 UV 且只在受伤和大招时出现；"减少闪光与晃动"开关（震屏 ×0.3、色差 0、泛光 ×0.6）。

## 18. 音频（100% WebAudio 实时合成，无任何音频文件）

- **音乐**："糖果合成波 / 芯片音乐"，每个世界有自己的调性和 BPM（第 11 节），标题、大厅、Boss（C 小调 140 BPM，每阶段升调加速）、无尽（逐渐加速升调）、胜利与失败小段、休息提醒的八音盒摇篮曲。每首歌有 A-A-B-C 段落结构和变奏，3 分钟的关卡不会听腻。
- **自适应分轨**（只在小节线切换）：底垫、鼓、贝斯、琶音、主旋律、狂热层 + 心跳层。风格 ≥ 10 加琶音，大招充满加主旋律，超载时刻加狂热层并 +8 BPM，剩 1 心时底垫低通 + 心跳底鼓，慢动作时整体低通 450 Hz 并降 6 dB，倒计时有鼓点前奏。
- **音效**：冲刺呼啸、推开"啵嘤"、咚（木鱼 + 叮当 + 弹簧）、解救脆响 + **五声音阶逐级上行**（连锁越长越高，跨 2 个八度）、完美（铃声和弦）、擦边左右声道"嗖"、捡水晶逐级升调、受伤、累了"噗"、大招（上扬 → 轰 → 闪烁）、升级号角、卡牌稀有度和弦、传送门调频上扬、冲冲引擎轰鸣、爆爆"哔哔"加速、激光嗡鸣、铁头"铛"、Boss 吼叫与砸地、UI 点击 / 领取 / 购买 / 扭蛋 / 升段。音效**从不为了卡拍而延迟**，只把音高吸附到当前调式。
- **方块语**：用合成的咿呀声代替配音，每位英雄音高和音色不同（小蓝中音、麻薯低音、闪闪高而快、星星带颤音），配合表情气泡而不是文字。
- 混音：总线压缩 + 限幅，最多 24 个同时发声，同帧相同音效限流，离线渲染验证不削波。

## 22. 性能预算

- 目标：中端笔记本和近年手机 60 fps。
- 绘制调用：繁忙波次 ≤ 150（所有敌人一个实例化网格、粒子 / 拾取物 / 阴影全部实例化）。
- 同屏敌人 ≤ 90，活跃粒子 ≤ 2000（低画质 ≤ 700）。
- 实测（无头浏览器）：80 个敌人 + 250 个拾取物 + 10 张卡时，核心玩法逻辑约 0.4 ms / 帧；音乐约占实时的 5–9%。
- 四档画质 + 自动降档；帧循环零分配；对象池预热。
- 单文件构建：`npm run build` 把所有模块 + three.js 打包进一个可离线双击打开的 HTML。
